Correlation tells us how strong a linear relationship is. Linear regression lets us use it: given a house's size, predict its price.

## One independent variable

We hypothesise a linear model

$$
y_i = \beta x_i + \alpha
$$

where $y_i$ is the price of house $i$, $x_i$ its size, $\beta$ the slope and $\alpha$ the intercept. Least squares picks the $\alpha$ and $\beta$ that minimise the **sum of squared errors** (residuals), our cost function $S$:

$$
S = \sum_{i=1}^n (y_i - \hat{y}_i)^2 = \sum_{i=1}^n (y_i - \alpha - \beta x_i)^2
$$

At the minimum, the partial derivatives of $S$ with respect to $\alpha$ and $\beta$ are both zero. (The [chain rule](/research/data-science/maths/calculus/chain-rule) and [partial derivatives](/research/data-science/maths/calculus/partial-derivatives) notes cover the calculus.)

### Finding $\alpha$

Differentiating with the chain rule, with $u = y_i - \alpha - \beta x_i$: the outer $u^2$ becomes $2u$, and the inner term differentiates to $-1$ with respect to $\alpha$. Setting the result to zero:

$$
0 = \sum_{i=1}^n -2(y_i - \alpha - \beta x_i)
$$

Dividing by $-2$ and splitting the sum, with $\sum_{i=1}^n \alpha = n\alpha$:

$$
0 = \sum_{i=1}^n y_i - n\alpha - \beta \sum_{i=1}^n x_i
\quad\Rightarrow\quad
\alpha = \frac{\sum y_i}{n} - \beta \frac{\sum x_i}{n}
$$

Those are just the means, so

$$
\alpha = \bar{y} - \beta \bar{x} \tag{1}
$$

The fitted line always passes through $(\bar{x}, \bar{y})$.

### Finding $\beta$

This time the inner term differentiates to $-x_i$:

$$
0 = \sum_{i=1}^n -2x_i(y_i - \alpha - \beta x_i)
\quad\Rightarrow\quad
0 = \sum_{i=1}^n (x_i y_i - \alpha x_i - \beta x_i^2)
$$

Substituting $\alpha$ from (1):

$$
0 = \sum_{i=1}^n (x_i y_i - \bar{y} x_i + \beta \bar{x} x_i - \beta x_i^2)
= \sum_{i=1}^n (x_i y_i - \bar{y} x_i) - \beta \sum_{i=1}^n (x_i^2 - \bar{x} x_i)
$$

so

$$
\beta = \frac{\sum_{i=1}^n (x_i y_i - \bar{y} x_i)}{\sum_{i=1}^n (x_i^2 - \bar{x} x_i)} \tag{2}
$$

which is the same as $\text{cov}(x, y) / \text{var}(x)$.

### In short

1. Calculate $\beta$ with (2).
2. Substitute it into (1) to get $\alpha$.
3. Predict with $\hat{y} = \beta x + \alpha$.

```python
def get_beta(x: np.ndarray, y: np.ndarray) -> float:
    numerator = np.sum((x * y) - (y.mean() * x))
    denominator = np.sum((x**2) - (x.mean() * x))
    return numerator / denominator


def get_alpha(x: np.ndarray, y: np.ndarray) -> float:
    return y.mean() - get_beta(x, y) * x.mean()
```

## Multiple regression

With several independent variables, for example minutes a data scientist spends on a social network:

$$
\text{minutes} = \beta_1 \,\text{friends} + \beta_2 \,\text{work hours} + \beta_3 \,\text{has PhD} + \alpha
$$

the single number $x_i$ becomes a vector $x_{i1}, \ldots, x_{ik}$:

$$
y_i = \beta_1 x_{i1} + \cdots + \beta_k x_{ik} + \alpha
$$

and the parameters become a vector $\beta$. We assume the columns of $x$ are _linearly independent_: no column can be written as a weighted sum of the others. Otherwise the coefficients are not uniquely determined.
